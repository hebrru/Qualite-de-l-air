📘 AirMonitor ESP32 – Capteur Qualité d’Air + Mise à Jour OTA (GitHub)

AirMonitor ESP32 est un système complet de mesure de qualité d’air basé sur :

ENS160 (TVOC, eCO₂, AQI)

AHT21 (Température & Humidité)

Écran ST7789 240×240

ESP32-WROOM-32

MQTT Home Assistant (auto-découverte)

Mises à jour OTA automatiques via GitHub

Ce dépôt héberge le firmware compilé, la version actuelle, ainsi que les fichiers OTA permettant une mise à jour totalement automatique.

🚀 Fonctionnalités

✔ Mesure en temps réel : Température, Humidité, eCO₂, TVOC, AQI

✔ Affichage sur écran TFT ST7789 (240x240)

✔ Détection automatique dans Home Assistant via MQTT Discovery

✔ Rappel d’état : Très bon / Bon / Moyen / Mauvais / Très mauvais

✔ Auto-calibration du ENS160

✔ Mise à jour OTA automatique connectée à GitHub

✔ Installation simple même pour débutants

🔧 Matériel compatible

ESP32-WROOM-32 DevKit

Capteur ENS160 (5V/3.3V I2C)

AHT21 température/humidité

Écran TFT ST7789 (SPI 240×240)
